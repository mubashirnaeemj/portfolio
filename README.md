# Mubashir Naeem Janjua — Portfolio

A personal portfolio site for **Mubashir Naeem Janjua**, an AI Automation Engineer focused on building production-grade AI systems, workflow automation, and backend infrastructure.

**Live site:** [https://mubashir-naeem-janjua.lovable.app](https://mubashir-naeem-janjua.lovable.app)

## Stack

- **Framework:** TanStack Start (React + Vite)
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4
- **UI Components:** shadcn/ui
- **Animation:** Framer Motion
- **Icons:** Lucide React

## Features

- Editorial dark-mode design with custom typography and motion
- Interactive architecture diagrams for key projects
- Project case studies with problem/solution breakdowns
- Real-time GitHub contribution heatmap
- Skills, experience timeline, and contact sections
- Resume download link

## Getting Started

```bash
bun install
bun run dev
```
